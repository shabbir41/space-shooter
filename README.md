# Space Shooter Game  

## Overview  
This Space Shooter game is a dynamic and challenging arcade-style game developed in Unity using C#. Players engage in battles against waves of enemies, progressing through increasingly difficult levels with adaptive mechanics and immersive visuals.  

## Features  
- **Dynamic Gameplay**: Progressive difficulty with decreasing enemy spawn intervals based on enemies count.  
- **Power-Up System**: Includes triple shots, shields, and speed boosts to enhance gameplay variety.  
- **Enemy AI**: Advanced behaviors, including firing commander and boss enemies, for strategic challenges.  
- **Dynamic Visuals**: Runtime post-processing adjustments create adaptive backgrounds that evolve with player progress.  

## Technical Implementation  
- **Object Pooling**: Efficient memory usage for seamless spawning of enemies and projectiles.  
- **Modular Design**: Components for enemy spawning, power-ups, and visual effects enable scalability and easy customization.  
- **Optimized Performance**: Ensures smooth gameplay on various platforms.  

## Future Enhancements  
- Additional power-ups and enemy types.  
- Expanded levels with new challenges.  
- Multiplayer mode for co-op gameplay.  

## Getting Started  
Clone the repository and open it in Unity to explore and play the game.
